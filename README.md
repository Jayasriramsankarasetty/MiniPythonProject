# 🖌️ Tkinter Paint Application

A simple yet Paint application built using **Python**, **Tkinter**, and **Pillow (PIL)**. It supports freehand drawing, shape tools, erasing, undo/redo functionality, color selection, and saving your artwork as an image file.

---

## 🚀 Features

- 🎨 **Pen & Brush** tool for freehand drawing  
- 🧼 **Eraser** tool to remove mistakes  
- 📐 **Shape tools** – Line, Rectangle, Circle, Square, Triangle, Diamond  
- 🌈 **Color picker**  
- ✏️ Adjustable **pen/brush size**  
- 🔄 **Undo** and **Redo** functionality  
- 🧹 **Clear** entire canvas  
- 💾 **Save** your artwork as a `.png` or `.jpg` image  
- 🖼️ Clean and modern UI layout  

---

- Python 3.x  
- Pillow (PIL)
